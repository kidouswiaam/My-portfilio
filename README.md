## Recommended Image Specifications
- **Size**: 800x600 pixels (16:9 aspect ratio)
- **Format**: JPG, PNG, or WebP
- **File naming**: Use descriptive names (e.g., `coffee-shop.jpg`, `ecommerce-platform.jpg`)
